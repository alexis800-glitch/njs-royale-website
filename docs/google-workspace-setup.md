## Setup sequence (to run when approved)
1. **Sign up** for Google Workspace with domain `njsbeachresort.com`; create the admin user.
2. **Verify domain ownership** — Google issues ONE of:
   - a **TXT** record `google-site-verification=XXXXXXXX` (value generated by Google — copy exactly), **or**
   - an MX-based / CNAME verification. Use whichever Google presents.
3. **Add MX records** (Google's current standard is a single MX):
   - `@  MX  1  smtp.google.com`  (confirm exact host/priority in the Admin console — Google has consolidated from the old 5-record set to a single `smtp.google.com` for new tenants; use what the console shows).
4. **Email authentication** (add after mailboxes exist):
   - **SPF (TXT on `@`):** `v=spf1 include:_spf.google.com ~all` (merge with any existing SPF — only one SPF record allowed).
   - **DKIM (TXT on `google._domainkey`):** value generated in Admin → Apps → Google Workspace → Gmail → Authenticate email. Copy the generated key exactly, then turn on DKIM signing.
   - **DMARC (TXT on `_dmarc`):** start monitoring-only: `v=DMARC1; p=none; rua=mailto:<dmarc-reports@njsbeachresort.com>;` then tighten to `p=quarantine`/`p=reject` after reviewing reports.
5. **Create mailbox** reservations@njsbeachresort.com; set display name "NJS Royale Beach Resort".
6. **Test** send/receive both directions; check SPF/DKIM/DMARC pass (e.g. send to a checker, review headers).

## Interaction with the website / Vercel
- Adding MX/SPF/DKIM/DMARC for email does **not** affect the Vercel web hosting or the `www`/apex web routing — email and web DNS are separate record types. Do not remove the existing A/CNAME records Vercel relies on for the site.
- Only **after** the mailbox is live and tested should reservations@njsbeachresort.com be published on the website (single small edit to `BookCTA.tsx` + `privacy/page.tsx`; currently intentionally absent).
